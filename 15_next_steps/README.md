# Next Steps — Course Summary & AI Agents

ဒီ module သည် 'Python for AI' သင်ခန်းကြားမှုကို အဆုံးသတ်သည့် module ဖြစ်ပြီး၊ တစ်ကြိမ်လုံး သင်ယူခဲ့သမျှကို ပြန်လည်သုံးသပ်ပေးမည့် module ဖြစ်ပါသည်။

## ဒီ module မှာ ဘာသင်မလဲ

- သင်ခန်းကြားမှု တစ်ခုလုံး၏ အဓိကအချက်များကို အကျဉ်းချုပ် ပြန်လည်သုံးသပ်ခြင်း
- သင်ခန်းကြားမှုအပေါ် အမြင်/feedback ပေးရန် လမ်းညွှန်ခြင်း
- နောက်ထပ် ဆက်လက်သင်ယူရမည့် အဆင့် — Python ဖြင့် AI agents တည်ဆောက်ခြင်း — ကို မိတ်ဆက်ခြင်း

## သင်ခန်းကြားမှု အကြောင်းအရာများ

1. **Course Summary** — သင်ယူခဲ့သော Python အခြေခံကနေ AI အထိ အကြောင်းအရာတွေကို အတူတကွ ပြန်ကြည့်ခြင်း
2. **Feedback** — သင်ခန်းကြားမှုအတွက် သင့်အာရုံစိုက်မှု၊ အကြံပေးချက်များ ပေးဆက်သွင်းနည်း
3. **Continue Learning: AI Agents** — နောက်အဆင့်ဖြစ်သော Python ဖြင့် AI agents တည်ဆောက်ခြင်း သင်ခန်းကြားမှုကို ဆက်လက်သင်ယူနည်း

## ယခင်အဆင့် သင်ယူပြီးဖြစ်ရမည့်အချက်များ (Prerequisites)

- Python basics: variables, functions, loops, data structures
- Python နှင့် AI ဆိုင်ရာ အခြေခံသဘောတရားများ (ရှေ့ module များမှ)
- အခြေခံ coding လေ့ကျင့်ခန်းများ လုပ်ဆောင်ခဲ့ဖူးခြင်း

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

- သင်ခန်းကြားမှုကို ပြီးဆုံးပြီးနောက် မိမိသင်ယူတတ်မြောက်ထားသည်များကို စစ်ဆေးလိုသောအခါ
- နောက်ထပ် လေ့လာစရာ ရွေးချယ်ရန် ဆုံးဖြတ်ချက် ချမှတ်လိုသောအခါ
- AI agents တည်ဆောက်ခြင်းကို ဆက်လက် လေ့လာလိုသောအခါ
