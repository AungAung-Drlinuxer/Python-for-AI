## အချက် ၃ — Continue Learning: Build AI Agents in Python

### ဘာကို ဆိုလိုတာလဲ

AI agents ဆိုသည်မှာ ဆုံးဖြတ်ချက်ချနိုင်ပြီး တာဝန်များကို အလိုအလျောက် လုပ်ဆောင်နိုင်သော AI ပရိုဂရမ်များ ဖြစ်ပါသည်။ Python ဖြင့် AI agents တည်ဆောက်ခြင်းသည် ဤသင်ခန်းကြားမှု၏ နောက်အဆင့် ဖြစ်ပါသည်။

### ဘာကြောင့် လဲ

AI agents များသည် AI နယ်ပယ်တွင် လက်တွေ့အသုံးအများဆုံး အပိုင်းများထဲမှ တစ်ခု ဖြစ်ပါသည်။ ဤသင်ခန်းကြားမှုတွင် သင်ယူခဲ့သော Python အခြေခံများသည် ထိုနောက်အဆင့်အတွက် အခြေခံကျပါသည်။

### ဘယ်လို အလုပ်လုပ်လဲ

AI agent တစ်ခုသည် အခြေခံအားဖြင့် — input လက်ခံရန်၊ ဆုံးဖြတ်ချက်ချရန်၊ လုပ်ဆောင်ချက် ပြုလုပ်ရန် — ဟူ၍ အဆင့်များဖြင့် အလုပ်လုပ်ပါသည်။ အောက်တွင် ရိုးရိုးရှင်းရှင်း agent အယူအဆကို Python function ဖြင့် ပြသထားပါသည်။

### ဥပမာ

```python
# A very simple example of an "agent" idea:
# it takes input, makes a decision, and acts

def simple_agent(task):
    # The agent receives a task
    if "greet" in task:
        return "Hello! How can I help you?"
    elif "summarize" in task:
        return "Here is a short summary."
    else:
        return "Task not recognized."

# Give the agent some tasks
print(simple_agent("greet the user"))
# Expected output: Hello! How can I help you?

print(simple_agent("summarize the text"))
# Expected output: Here is a short summary.
```

### လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ

AI agents တွင် အသုံးပြုသော အခြေခံကျသည့် ပုံစံများ — input လက်ခံခြင်း၊ ဆုံးဖြတ်ချက်ချခြင်း၊ တုံ့ပြန်ခြင်း — ကို နားလည်ထားပါက နောက်အဆင့် လေ့လာမှုတွင် ပိုမိုလွယ်ကူပါသည်။ Python functions နှင့် dictionaries များကို ကျွမ်းကျင်စွာ အသုံးပြုနိုင်ခြင်းသည် အရေးကြီးပါသည်။
