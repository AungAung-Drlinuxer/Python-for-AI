# Data Structures — Lists, Dictionaries, Tuples, Sets

Python မှာ data အများကြီးကို တစ်နေရာတည်းမှာ သိမ်းဆည်းနိုင်တဲ့ container ၄ မျိုးအကြောင်း ဒီ module မှာ လေ့လာမည်။

## ဒီ module မှာ ဘာသင်မလဲ

- List တည်ဆောက်ခြင်းနဲ့ အသုံးပြုခြင်း
- Dictionary နဲ့ key-value data သိမ်းဆည်းခြင်း
- Tuple နဲ့ မပြောင်းလဲနိုင်တဲ့ data သိမ်းခြင်း
- Set နဲ့ unique value များကို စီမံခြင်း
- Zero-based indexing သဘောတရား

## သင်ခန်းများ

1. **Lists** — အစီအစဉ်ရှိတဲ့၊ ပြောင်းလဲနိုင်တဲ့ data collection။ ဥပမာ — ဝယ်စာရင်း။
2. **Dictionaries** — key နဲ့ value တွဲကာ ရှာဖွေနိုင်တဲ့ structure။ ဥပမာ — ဖုန်းစာရင်း။
3. **Tuples** — မပြောင်းလဲနိုင်တဲ့ (immutable) data collection။ ဥပမာ — coordinates။
4. **Sets** — duplicate မရှိတဲ့ unique value များ။ ဥပမာ — ထူးခြားတဲပစ္စည်း အိတ်။
5. **Indexing** — ပထမဆုံး item က position 0 ကနေ စတင်တာ။

## လိုအပ်ချက်များ (Prerequisites)

- Python variables နဲ့ data types အခြေခံ
- String နဲ့ number များကို သိရှိခြင်း
- Python environment တစ်ခု ထည့်သွင်းပြီးဖြစ်ခြင်း

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

- AI project တစ်ခုမှာ data အများကြီးကို စနစ်တကျ သိမ်းချင်တဲ့အခါ
- User profile တွေ၊ model result တွေကို key နဲ့ ရှာချင်တဲ့အခါ
- ပြောင်းလဲမနေဘဲ ရှိတဲ့ data (coordinate, config) သိမ်းချင်တဲ့အခါ
- Duplicate ဖယ်ရှားပြီး unique value တွေချင်းတည်း စစ်ချင်တဲ့အခါ
