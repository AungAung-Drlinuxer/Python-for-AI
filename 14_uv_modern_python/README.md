# Modern Python — uv Package Manager

ဒီ module မှာ Python project တွေကို မြန်ဆန်တဲ့ `uv` tool နဲ့ စီမံခန့်ခွဲနည်းကို သင်ရမည်။

## ဒီ module မှာ ဘာသင်မလဲ

- pip ရဲ့ ပြဿနာတွေကို နားလည်မည်
- `uv` ဆိုတာ ဘာလဲ၊ ဘာကြောင့် အသုံးပြုသင့်တာလဲ သင်ရမည်
- `uv` နဲ့ project အသစ် ဖန်တီးနည်း လက်တွေ့ လုပ်ရမည်
- project တစ်ခုကို အစကနေ အဆုံးအထိ ထူထောင်နည်း full workflow ကို သင်ရမည်

## Lesson စာရင်း

1. **uv ဆိုတာ ဘာလဲ (uv-intro)**
   - `uv` ရဲ့ သမိုင်းကြောင်းနဲ့ လုပ်ဆောင်ချက်များ
   - pip ထက် ၁၀ ဆကနေ ၁၀၀ ဆအထိ မြန်ပုံ
   - Rust နဲ့ ရေးထားပုံ၊ pip, venv, pip-tools, pyenv တွေကို အစားထိုးနိုင်ပုံ

2. **uv နဲ့ Virtual Environment (uv-virtual-env)**
   - virtual environment ဆိုတာ ဘာလဲ
   - `uv` နဲ့ environment ဖန်တီးပုံ၊ သုံးပုံ
   - pip ခေတ်က venv command တွေရဲ့ ရှုပ်ထွေးမှုနဲ့ နှိုင်းယှဉ်ခြင်း

3. **Complete Setup Workflow (complete-setup)**
   - project တစ်ခုကို အစကနေ စတင်ပုံ
   - dependency ထည့်သွင်းပုံ၊ run ပုံ
   - start-to-finish workflow လက်တွေ့ လေ့ကျင့်ခန်း

## မသင်မီ လိုအပ်ချက်များ (Prerequisites)

- Python အခြေခံ သင်ခန်းစာတွေကို ဖတ်ပြီးဖြစ်ရမည်
- Terminal (command line) ကို အခြေခံ level မျှ သိရမည်
- pip နဲ့ package install လုပ်ဖူးရင် ပိုကောင်းသည် (မလုပ်ဖူးလည်း ရသည်)

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

AI project တွေမှာ library တွေ များပြားလှသည်။ `uv` ကို သုံးရင် environment ကို မြန်မြန်ဆန်ဆန် ထူထောင်ပြီး အချိန်ကုန်သက်သာသည်။ Machine learning project အသစ်တစ်ခု စရင် `uv` က အကောင်းဆုံး ရွေးချယ်မှု ဖြစ်သည်။
