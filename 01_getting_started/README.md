# Getting Started — Environment Setup

Python ကို စတင်အသုံးပြုနိုင်ရန် ကွန်ပျူတာပေါ်တွင် ပြင်ဆင်ခြင်းနှင့် အသုံးပြုမည့် ကိရိယာများကို ထိုးထိုးထွင်ထွင် သိရှိစေသည့် module ဖြစ်သည်။

## ဒီ module မှာ ဘာသင်မလဲ

- Python ဆိုတာ ဘာလဲ နှင့် ဘာကြောင့် AI အတွက် အသုံးများလဲ
- Windows, macOS, Linux တို့ပေါ်တွင် Python install လုပ်နိုင်ခြင်း
- VS Code editor ကို setup လုပ်ခြင်းနှင့် workspace ဖန်တီးခြင်း
- ပထမဆုံး Python file ရေးပြီး run ကြည့်ခြင်း
- Course resources များကို အသုံးပြုနိုင်ခြင်း
- Virtual environment ဖန်တီးခြင်းနှင့် package (pip) install လုပ်ခြင်း
- Interactive Python (REPL) ကို အသုံးပြုခြင်း

## သင်ခန်းစာ စာရင်း

1. **What is Python** — Python ဘာသာစကားရဲ့ အခြေခံသဘောတရားနှင့် အားသာချက်များ
2. **Installing Python** — Windows, macOS, Linux အတွက် install လုပ်ပုံ အဆင့်ဆင့်
3. **VS Code Introduction & Setup** — VS Code ကို download လုပ်ပြီး Python extension install လုပ်ပုံ
4. **VS Code Workspace** — Project workspace folder ဖန်တီးပြီး စနစ်တကျ စီစဉ်ပုံ
5. **First Python File** — `hello.py` file ရေးပြီး terminal ကနေ run ပုံ
6. **Course Resources** — သင်ခန်းစာအားလုံးနှင့် reference များကို ရှာဖွေပုံ
7. **Virtual Environments** — Project တစ်ခုစီအတွက် သီးသန့် Python environment ဖန်တီးပုံ
8. **Packages and pip** — `pip` ဖြင့် third-party package များ install လုပ်ပုံ
9. **Interactive Python** — REPL ထဲမှာ တိုက်ရိုက် code စမ်းသပ်ပုံ

## မသင်မီ လိုအပ်ချက်များ (Prerequisites)

- ကိုယ်ပိုင် ကွန်ပျူတာ (Windows, macOS သို့မဟုတ် Linux)
- Internet ချိတ်ဆက်မှု (download လုပ်ရန်အတွက်)
- Programming အတွေ့အကြုံ လုံးဝ မလိုအပ်ပါ — ဒီ module က အစပြုသူများအတွက် ဖြစ်သည်

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

AI project တစ်ခု စတင်လုပ်ချင်တဲ့ အခိုက်တိုင်း ဒီ module ရဲ့ အသိပညာများက အသုံးဝင်ပါသည်။ Python ကို install လုပ်ခြင်း၊ VS Code နဲ့ အလုပ်လုပ်ခြင်း၊ virtual environment နဲ့ package တွေကို စီမံခြင်း — ဒီအချက်အလက်တွေက နောက်ပိုင်း module တိုင်းမှာ အခြေခံ ဖြစ်ပါသည်။
