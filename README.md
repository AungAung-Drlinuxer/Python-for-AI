# Python for AI

ဒီ course က AI ဆီ ဦးတည်ထားတဲ့ Python သင်တန်းဖြစ်ပြီး စတင်လေ့လာသူများအတွက် အဓိကထား ရေးသားထားပါတယ်။ Theory ချည်းသက်သက် မဟုတ်ဘဲ လက်တွေ့လုပ်ကိုင်နိုင်မယ့် hands-on နည်းလမ်းနဲ့ သင်ကြားပေးမှာ ဖြစ်ပါတယ်။ Instructor က Dave Ebbelaar ဖြစ်ပြီး Python နဲ့ နှစ်ပေါင်း ၁၂ နှစ်ကျော် အတွေ့အကြုံရှိပြီး ကျောင်းသား သောင်း ၃ ကျော်အထိ သင်ကြားခဲ့ဖူးသူပါ။

## ဒီ course မှာ ဘာသင်မလဲ

- **Set up like a pro** — Python environment၊ VS Code၊ virtual environments၊ packages တွေကို professional တစ်ယောက်လို တပ်ဆင်နိုင်မယ်
- **Learn Python fast** — Syntax ကနေစချင့်လက်တွေ့ project တွေအထိ မြန်မြန်နဲ့ ခြေရာမကျစေဘဲ သင်ယူနိုင်မယ်
- **Build AI agents** — Course ပြီးဆုံးရင် AI agents တည်ဆောက်တဲ့ နောက်ထပ်အဆင့်အထိ ဆက်လက်လေ့လာနိုင်မယ်
