# Module: Functions — ပြန်သုံးနိုင်တဲ့ Code Block တွေ

ဒီ module မှာ Python function တွေရေးနည်းကို သင်မယ်။ Function ဆိုတာ အမည်ပေးထားတဲ့ code block တစ်ခုဖြစ်ပြီး ထပ်ခါထပ်ခါ ခေါ်သုံးလို့ရတယ်။

## ဒီ module မှာ ဘာသင်မလဲ

- Function ဆိုတာ ဘာလဲ၊ ဘာကြောင့် လိုအပ်လဲ
- Function တစ်ခုကို ဘယ်လို define လုပ်မလဲ
- Parameter နဲ့ argument တွေကို ဘယ်လို သုံးမလဲ
- return value ကို ဘယ်လို ရယူမလဲ

## Lessons

1. **Defining Functions** — `def` keyword နဲ့ function တစ်ခုကို ဘယ်လို ဖန်တီးမလဲ၊ ဘယ်လို ခေါ်မလဲကို သင်မယ်။
2. **Parameters** — Function ထဲကို input data တွေ ဘယ်လို ပို့မလဲကို သင်မယ်။
3. **Return Values** — Function ကရဲ့ ရလဒ်ကို ဘယ်လို ပြန်ပေးမလဲကို သင်မယ်။

## Prerequisites

- Python variables နဲ့ data types (int, float, str, bool) အသုံးပြုနိုင်ရမယ်။
- `if/else` နဲ့ loop အခြေခံကို နားလည်ထားရမယ်။
- `print()` နဲ့ `len()` လို built-in function တွေကို သုံးဖူးရမယ်။

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

- တူညီတဲ့ တွက်ချက်မှု (ဥပမာ — tax တွက်ခြင်း) ကို နေရာများများမှာ သုံးရင်။
- Code ရှည်ကြီးကို အစိတ်စိတ် ခွဲစီမံခန့်ခွဲချင်ရင်။
- AI project တွေမှာ utility function တွေ ရေးချင်ရင်။
