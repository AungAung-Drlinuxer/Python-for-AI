# Module ၁ — လက်တွေ့ စာတမ်းများ (Exercises)

အောက်ပါ စာတမ်းများကို အလွယ်ဆုံးမှ ခက်ခဲဆုံးသို့ အစီအစဉ်အတိုင်း လုပ်ကြည့်ပါ။ Python ကို ကွန်ပျူတာမှာ run ဖို့ online interpreter (ဥပမာ — replit.com) ဒါမှမဟုတ် ကိုယ်ပိုင် setup တစ်ခုကို သုံးနိုင်ပါသည်။

## ၁။ သင်တန်းဆရာ profile ရေးပါ

သင်တန်းဆရာ Dave Ebbelaar ၏ အချက်အလက်တွေကို print ထုတ်ပါ — နာမည်၊ Python အတွေ့အကြုံ (၁၂ နှစ်) နှင့် သင်ကြားခဲ့သော ကျောင်းသားအရေအတွက် (၃၀၀၀၀)။

**အကြံပြုချက် —** `print()` function ကို အကြိမ်ကြိမ် သုံးလို့ရပါသည်။

**မျှော်မင်းရမည့် အပြုအမူ —** စာသား ၃ ကြောင်း ထွက်ပေါ်ရပါမည်။

**Hints:** `print()` function ကို သုံးပြီး စာသားတစ်ကြောင်းချင်းစီ တိုက်ရိုက် ရိုက်ထုတ်နိုင်ပါသည်။

**Expected behavior:** `print()` function သုံးပြီး Dave Ebbelaar ၏ နာမည်၊ Python အတွေ့အကြုံ ၁၂ နှစ်နှင့် သင်ကြားခဲ့သော ကျောင်းသား ၃၀၀၀၀ စာသား ၃ ကြောင်း အသီးသီး ထွက်ပေါ်စေရမည်။

## ၂။ Python learning အပိုင်း ၂ ပိုင်းကို list ဖြင့် သိမ်းပါ

Python လေ့လာမှုတွင် အပိုင်း ၂ ပိုင်းရှိသည် — "syntax" နှင့် "workflow"။ ဒီအပိုင်း နှစ်ခုကို Python list တစ်ခုထဲ သိမ်းပြီး `for` loop ဖြင့် တစ်ခုချင်း print ထုတ်ပါ။

**အကြံပြုချက် —** `for part in parts:` ပုံစံကို သုံးပါ။

**မျှော်မင်းရမည့် အပြုအမူ —** "Part: syntax" နှင့် "Part: workflow" ဆိုတဲ့ စာကြောင်း နှစ်ကြောင်း ထွက်ရပါမည်။

**Hints:** list တစ်ခုထဲတွင် အပိုင်းနှစ်ခုကို string များအဖြစ် သိမ်းပြီး `for` loop ထဲတွင် `print()` ကို `"Part: " + part` သို့မဟုတ် f-string ဖြင့် တွဲသုံးပါ။

**Expected behavior:** ပရိုဂရမ်ကို လည်ပတ်စေသောအခါ "Part: syntax" နှင့် "Part: workflow" ဆိုသည့် စာကြောင်းနှစ်ကြောင်းကို အစဉ်လိုက် ထွက်ပေါ်လာရမည်။

## ၃။ ကိုယ်ပိုင် profile ဖန်တီးပါ

ကိုယ့်နာမည်နှင့် သင်ယူလိုတဲ့ ရည်မှန်းချက်တစ်ခုကို variable နှစ်ခုမှာ သိမ်းပြီး၊ sentence တစ်ကြောင်း အဖြစ် ပေါင်းစပ် print ထုတ်ပါ။

**အကြံပြုချက် —** f-string (ဥပမာ — `f"..."`) ကို သုံးကြည့်ပါ။

**မျှော်မင်းရမည့် အပြုအမူ —** ကိုယ့်နာမည်နဲ့ ရည်မှန်းချက်ပါတဲ့ sentence တစ်ကြောင်း ထွက်ရပါမည်။

**Hints:** variable နှစ်ခုမှာ name နဲ့ goal ကို သိမ်းပြီး f-string ကို သုံးပြီး print ထုတ်ပါ။

**Expected behavior:** ဥပမာ name = "Aung" နှင့် goal = "Python ကို လေ့လာခြင်း" ဆိုပါက `My name is Aung and my goal is Python ကို လေ့လာခြင်း` စသည့် ပုံစံဖြင့် ကိုယ့်နာမည်နှင့် ရည်မှန်းချက် ပါဝင်သော sentence တစ်ကြောင်းကို မျက်နှာပြင်တွင် တွေ့ရမည်။

## ၄။ AI project အိုင်ဒီယာစာရင်း

AI နဲ့ လုပ်ကြည့်ချင်တဲ့ project အိုင်ဒီယာ ၃ ခုကို list တစ်ခုထဲ ရေးပြီး၊ အနံပါတ်နံပါတ်နဲ့ တွဲပြီး print ထုတ်ပါ။

**အကြံပြုချက် —** `for` loop ထဲမှာ index နံပါတ်နဲ့ တွဲဖို့ `range(len(...))` ကို သုံးလို့ရပါသည်၊ ဒါမှမဟုတ် `enumerate()` ကို ရှာကြည့်ပါ။

**မျှော်မင်းရမည့် အပြုအမူ —** "1. ..."၊ "2. ..."၊ "3. ..." ပုံစံနဲ့ ၃ ကြောင်း ထွက်ရပါမည်။

**Hints:** `enumerate()` ကို `start=1` နဲ့ သုံးပြီး index နဲ့ အိုင်ဒီယာကို တွဲဖို့ `f-string` ကို စမ်းကြည့်ပါ။

**Expected behavior:** `1. ...`၊ `2. ...`၊ `3. ...` ပုံစံနဲ့ AI project အိုင်ဒီယာ ၃ ခု အနံပါတ်နံပါတ်နဲ့ တွဲပြီး ၃ ကြောင်း print ထွက်လာရမည်။

## ၅။ AI assistant ကို မေးရမယ့် မေးခွန်းများ ဖန်တီးပါ

AI assistant တစ်ယောက်ကို သင်ခန်းစာတစ်ခုအကြောင်း ရှင်းပြခိုင်းဖို့ prompt ၃ ခုကို Python code ဖြင့် ဖန်တီးပြီး print ထုတ်ပါ။ ဥပမာ — "Explain variables in Python with a simple example for a beginner."

**အကြံပြုချက် —** topic တွေကို list ထဲ သိမ်းပြီး loop နဲ့ ချိတ်ဆက်ပါ။

**မျှော်မင်းရမည့် အပြုအမူ —** မေးခွန်း ပုံစံ ၃ ခု ထွက်ရပါမည်။

**Hints:** topic များကို `for` loop ဖြင့် ထပ်ဆောင်းပြီး f-string ကို အသုံးပြုကာ prompt string များကို `print()` ဖြင့် ထုတ်ပါ။

**Expected behavior:** program ကို run လိုက်သောအခါ "Explain variables in Python with a simple example for a beginner." စသည့် topic ၃ ခုအတွက် AI assistant ကို မေးရမယ့် prompt မေးခွန်းပုံစံ ၃ ခုကို အသီးသီး print ထုတ်ပြသည်ကို လုပ်ဖော်ကိုင်ဖက် မြင်ရမည်။

## ၆။ သင်ယူမှု progress tracker ရေးပါ

သင်ပြီးမြောက်ခဲ့တဲ့ module နံပါတ်တွေနဲ့ ကျန်နေတဲ့ module နံပါတ်တွေကို သီးသန့်စီ သိမ်းပြီး၊ progress percentage ကိုတွက်ပြီး print ထုတ်ပါ။ ဥပမာ — module ၁၀ ခုအနက် ၃ ခု ပြီးပြီးဆိုရင် "Progress: 30%" ထွက်ရပါမည်။

**အကြံပြုချက် —** `len()` function နှင့် ကိန်းရိုက် `( ) * 100` ကို သုံးပါ။

**မျှော်မင်းရမည့် အပြုအမူ —** မှန်ကန်တဲ့ percentage တစ်ခု ထွက်ရပါမည်။

**Hints:** ပြီးမြောက်ထားသော module စာရင်း (list) တစ်ခုနှင့် စုစုပေါင်း module အရေအတွက်ကို သီးသန့်သတ်မှတ်ပြီး `len()` နှင့် အပိုင်းခြောက် ၁၀၀ နှင့် မြှောက်ပြီး `round()` သုံးကာ `f-string` ဖြင့် `"Progress: XX%"` ပုံစံ print ထုတ်ကြည့်ပါ။

**Expected behavior:** ပြီးမြောက်ထားသော module ၃ ခုနှင့် စုစုပေါင်း module ၁၀ ခု သတ်မှတ်၍ run လိုက်သည့်အခါ terminal တွင် `Progress: 30%` ဟု မှန်ကန်စွာ ထွက်ပေါ်ရမည်။
