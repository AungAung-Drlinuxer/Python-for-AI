# Module ၁ — Course Welcome (သင်ခန်းစာ မိတ်ဆက်)

ဒီ module သည် "Python for AI" သင်တန်း၏ အစိတ်အပိုင်းဖြစ်ပြီး၊ သင်တန်းအကြောင်း၊ ဘယ်သူအတွက် သင့်တော်လဲ၊ ဘယ်လိုလိုက်လို့ရလဲ၊ Python ကို ဘာကြောင့် ရွေးချယ်ရလဲနှင့် AI ကို အထောက်အကူပြုပြီး လေ့လာနည်းတို့ကို မိတ်ဆက်ပေးပါသည်။

## ဒီ module မှာ ဘာသင်မလဲ

- သင်တန်းဆရာ Dave Ebbelaar နှင့် သင်တန်းရင်းမြစ်အကြောင်း
- ဒီသင်တန်းသည် ဘယ်သူ့အတွက် သင့်တော်လဲ ဆိုတာကို နားလည်ခြင်း
- သင်တန်းကို ဘယ်လို လိုက်နာကြည့်ရမလဲ ဆိုတာကို သိခြင်း
- Python ဘာသာစကားကို ဘာကြောင့် ရွေးရလဲ ဆိုတာကို သိခြင်း
- AI assistant တွေကို သုံးပြီး ပိုမြန်စွာ လေ့လာနည်း

## လိုအပ်ချက်များ (Prerequisites)

-  programming အတွေ့အကြုံ လုံးဝမလိုဘူး — ဒီသင်တန်းက အစအလယ် ကျောင်းသားတွေအတွက် ဖြစ်ပါတယ်
- ကွန်ပျူတာတစ်လုံး (Windows, Mac ဒါမှမဟုတ် Linux)
- သင်ခန်းစာတွေကို လက်တွေ့ လိုက်လုပ်ဖို့ ဆန္ဒရှိမှု
