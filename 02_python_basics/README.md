# Python Basics — Building Blocks

Python ဘာသာစကားရဲ့ အခြေခံအုတ်မြစ်တွေကို စတင်သင်ကြားရမယ့် module ဖြစ်ပါတယ်။

## ဒီ module မှာ ဘာသင်မလဲ

- Programming ဆိုတာ တကယ်လက်တွေ့ ဘာလဲ ဆိုတာကို နားလည်မယ်။
- Python syntax စည်းမျဉ်းတွေနဲ့ ကုဒ်ရေးနည်းကို သင်မယ်။
- Error တွေကို ဖတ်နိုင်၊ နားလည်နိုင်လာမယ်။
- ကုဒ်ကို သပ်သပ်ရပ်ရပ် format လုပ်နည်း သင်မယ်။
- Variable တွေသုံးပြီး data သိမ်းနည်း သင်မယ်။
- Comment ရေးနည်း သင်မယ်။
- Operator တွေ (သချာညီမျှ / နှိုင်းယှဉ် / logical) သင်မယ်။
- String တွေကို လုပ်ငန်းခွဲနည်း သင်မယ်။
- Loop သုံးပြီး အလုပ်တွေကို ထပ်ခါထပ်ခါ လုပ်နည်း သင်မယ်။

## သင်ခန်းစာ စာရင်း

1. **Intro to Programming** — Program ဆိုတာ ဘာလဲ၊ computer က ဘယ်လို command တွေကို လိုက်နာလဲ။
2. **Python Syntax** — Python ရဲ့ ရေးသားစည်းမျဉ်းတွေ၊ indentation အရေးကြီးပုံ။
3. **Python Errors** — Error message တွေကို ဖတ်နည်း၊ ဘာကြောင့် အမှားဖြစ်လဲ ရှာနည်း။
4. **Formatting** — ကုဒ်ကို ဖတ်လွယ်အောင် စီစဉ်နည်း။
5. **Variables** — Data ကို နာမည်ပေးပြီး သိမ်းဆည်းနည်း။
6. **Comments** — ကုဒ်ထဲမှာ မှတ်ချက်ရေးနည်း။
7. **Operators** — သချာညီမျှ၊ နှိုင်းယှဉ်၊ logical operator တွေ။
8. **String Manipulation** — Text data ကို ပြင်ဆင်၊ ပေါင်းစပ်၊ ခွဲခြမ်းနည်း။
9. **Loops** — `for` နဲ့ `while` သုံးပြီး အလုပ်ထပ်လုပ်နည်း။

## သင်ယူရန် လိုအပ်ချက်များ (Prerequisites)

- ဒီ course ရဲ့ အစပိုင်းကို စတင်တဲ့သူတွေအတွက် ဖြစ်ပါတယ်။
- Programming အတွေ့အကြုံ လုံးဝမလိုအပ်ပါ။
- Computer တစ်လုံးမှာ Python install လုပ်ထားရမယ် (သို့မဟုတ်) online editor သုံးလို့ရတယ်။

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

ဒီ module က နောက်ပိုင်း AI project တွေအားလုံးရဲ့ အခြေခံဖြစ်ပါတယ်။ AI model တွေ၊ agent တွေကို Python နဲ့ပဲ ရေးရမှာ မဟုတ်ပေမယ့် data သန့်စင်တာ၊ prompt တည်ဆောက်တာ၊ ရလဒ်တွေ ပြသာနာတာ အားလုံးမှာ ဒီအခြေခံတွေ လိုအပ်ပါတယ်။
