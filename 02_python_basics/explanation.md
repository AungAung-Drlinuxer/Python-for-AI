# Python Basics — Building Blocks ရှင်းလင်းချက်

## ၁။ Programming ဆိုတာ ဘာလဲ

**ဘာကို ဆိုလိုတာလဲ** — Programming ဆိုတာ computer ကို လိုက်နာရမယ့် အဆင့်ဆင့် ညွှန်ကြားချက်တွေ ရေးပေးတာ ဖြစ်ပါတယ်။

**ဘာကြောင့် လဲ** — Computer က ကိုယ့်ဘာသာ မကြားတတ်ပါ။ တိတ်ကျတိကျ ရေးထားတဲ့ ညွှန်ကြားချက်တွေကိုပဲ လိုက်နာပါတယ်။

**ဘယ်လို အလုပ်လုပ်လဲ** — ကျွန်တော်တို့က ကုဒ်ရေးရင် အဆင့်လိုက် စဉ်းစားထားတဲ့ အလုပ်တွေကို Python ဘာသာနဲ့ ရေးပေးရပါတယ်။ Computer က အပေါ်ကနေ အောက်ကို တစ်ကြောင်းချင်း လိုက်ဖတ်ပြီး လက်တွေ့ကျကျ လုပ်ဆောင်ပါတယ်။

**လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ** — AI app တစ်ခု တည်ဆောက်မယ်ဆိုရင် "data ယူ -> သန့်စင် -> model ကို ပို့ -> ရလဒ်ပြ" ဆိုတဲ့ အဆင့်တွေကို ရေးပေးရပါတယ်။ ဒီအဆင့်တွေကို စဉ်းစားတတ်ဖို့ အရေးကြီးပါတယ်။

## ၂။ Python Syntax

**ဘာကို ဆိုလိုတာလဲ** — Syntax ဆိုတာ ဘာသာစကားတစ်ခုရဲ့ သဒ္ဒါစည်းမျဉ်းသဖွယ် ဖြစ်ပါတယ်။ Python မှာ ရေးပုံချက်ပုံ တိတ်ကျတဲ့ စည်းမျဉ်းတွေ ရှိပါတယ်။

**ဘာကြောင့် လဲ** — Syntax မှားရင် Python က ကုဒ်ကို လုံးဝ လုပ်ဆောင်ပေးမှာ မဟုတ်ပါဘူး။ သဒ္ဒါမှားတဲ့ စာကို လူက နားမလည်သလိုပါပဲ။

**ဘယ်လို အလုပ်လုပ်လဲ** — Python က indentation (space ထပ်ခြင်း) ကို တိတ်ကျစွာ သတိပြုပါတယ်။ Block တစ်ခုထဲက ကုဒ်တွေက တစ်ပြားချင်း တူညီတဲ့ indentation ရှိရမယ်။

**ဥပမာ**

```python
# Correct indentation
name = "Aung Aung"
if name == "Aung Aung":
 print("Hello!")
 print("Welcome to Python.")
print("Done.")
```

**လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ** — Indentation မှားတာဟာ beginner တွေ အများဆုံး ကြုံရတဲ့ ပြဿနာဖြစ်ပါတယ်။ `if`, `for` တို့နောက်မှာ မှန်ကန်တဲ့ indentation ရှိဖို့ အရေးကြီးပါတယ်။

## ၃။ Error တွေကို နားလည်ခြင်း

**ဘာကို ဆိုလိုတာလဲ** — Error ဆိုတာ Python က ကိုယ့်ကုဒ်ထဲမှာ နားမလည်နိုင်တဲ့ နေရာ တွေ့တဲ့အခါ ပြတဲ့ သတင်းစကားဖြစ်ပါတယ်။

**ဘာကြောင့် လဲ** — Error က ရန်သူမဟုတ်ပါဘူး၊ ကူညီသူဖြစ်ပါတယ်။ Error message ထဲမှာ ဘာကြောင့်မှားလဲ၊ ဘယ်လိုင်းမှာ မှားလဲ ဆိုတာ ပြောပြနေတာ ဖြစ်ပါတယ်။

**ဘယ်လို အလုပ်လုပ်လဲ** — Error message ကို အောက်ကနေ အပေါ်ကို ဖတ်ပါ။ နောက်ဆုံး line က အဓိက အကြောင်းပြချက် ဖြစ်ပြီး အပေါ်က ဘယ် file ဘယ်လိုင်းမှာ မှားလဲ ပြပါတယ်။

**ဥပမာ**

```python
# This code causes a NameError
print(greeting)
# NameError: name 'greeting' is not defined
```

**လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ** — Error ဖတ်တတ်ရင် ကုဒ်ရေးနေတုန်းကို ပြဿနာကိုယ်တိုင် ဖြေရှင်းနိုင်ပါတယ်။ Common error တွေက `SyntaxError`, `NameError`, `TypeError` တို့ ဖြစ်ပါတယ်။

## ၄။ Variables

**ဘာကို ဆိုလိုတာလဲ** — Variable ဆိုတာ data တစ်ခုကို နာမည်တစ်ခုနဲ့ သိမ်းဆည်းတဲ့ နေရာဖြစ်ပါတယ်။

**ဘာကြောင့် လဲ** — တစ်ခါသုံးပြီးသား data တွေကို နာမည်နဲ့ ခေါ်သုံးရင် ကုဒ် ဖတ်လွယ်ပြီး ပြင်ရလည်း လွယ်ပါတယ်။

**ဘယ်လို အလုပ်လုပ်လဲ** — `=` သင်္ကျန်းနဲ့ value တစ်ခုကို နာမည်တစ်ခုထဲ ထည့်ပါ။ နာမည်ကို ခေါ်ရင် အထဲက value ပြန်ထွက်လာပါတယ်။

**ဥပမာ**

```python
# Store data in variables
model_name = "GPT"
accuracy = 95
print(model_name)      # Output: GPT
print(accuracy)        # Output: 95

# Variables can be updated
accuracy = accuracy + 2
print(accuracy)       # Output: 97
```

**လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ** — AI project တိုင်းမှာ data တွေကို နာမည်ပေးပြီး သိမ်းဆည်းဖို့ လိုပါတယ်။ Model score တွေ၊ file path တွေ၊ user input တွေ အားလုံး variable ထဲ သိမ်းရပါတယ်။

## ၅။ Comments

Comment ဆိုတာ `#` နဲ့ စတဲ့ မှတ်ချက်ဖြစ်ပြီး Python က လုံးဝ လျစ်လျူရှုထားပါတယ်။ ကုဒ်ကို လူတွေ နားလည်လွယ်အောင် ရေးပေးတာ ဖြစ်ပါတယ်။ နောက်ပိုင်း ကိုယ့်ကုဒ်ကိုယ်တိုင် ပြန်ဖတ်တဲ့အခါ ဘာလုပ်နေလဲ မေ့မနေ ရပါတယ်။

## ၆။ Operators

**ဘာကို ဆိုလိုတာလဲ** — Operator တွေက တန်ဖိုးတွေကို စီမြံပြုလုပ်ပေးတဲ့ သင်္ကျန်းတွေ ဖြစ်ပါတယ်။ သုံးမျိုး ရှိပါတယ်။

**ဘာကြောင့် လဲ** — သချာညီမျှ (`+`, `-`, `*`, `/`)၊ နှိုင်းယှဉ် (`==`, `>`, `<`)၊ logical (`and`, `or`, `not`) ဆိုတဲ့ operator တွေကို သုံးပြီး ကုဒ်က ဆုံးဖြတ်ချက်တွေ ချနိုင်ပါတယ်။

**ဘယ်လို အလုပ်လုပ်လဲ** — နှိုင်းယှဉ် operator တွေက `True` (မှန်) ဒါမှမဟုတ် `False` (မှား) ပြန်ပေးပါတယ်။ Logical operator တွေက စစ်မှုတွေကို ပေါင်းစပ်ပေးပါတယ်။

**ဥပမာ**

```python
# Math operators
score = 80 + 10      # 90
half = score / 2     # 45.0

# Comparison operators
print(score > 50)    # Output: True
print(score == 90)   # Output: True

# Logical operators
is_ready = score > 50 and half > 20
print(is_ready)      # Output: True
```

**လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ** — AI system တွေမှာ "score ဒီအတိုင်းအတာထဲ ရှိလား" ဆိုတဲ့ စစ်ဆေးမှုတွေ အမြဲလိုပါတယ်။ Operator တွေက ဒီဆုံးဖြတ်ချက်တွေရဲ့ အခြေခံဖြစ်ပါတယ်။

## ၇။ String Manipulation

**ဘာကို ဆိုလိုတာလဲ** — String ဆိုတာ text data ဖြစ်ပြီး `"..."` အတွင်း ရေးပါတယ်။ String manipulation က text ကို ပြင်ဆင်၊ ပေါင်းစပ်၊ ခွဲခြမ်းတာ ဖြစ်ပါတယ်။

**ဘာကြောင့် လဲ** — AI မှာ user ရေးတဲ့ text တွေကို သန့်စင်ပြီးမှ model ကို ပို့ရတာမို့ text ကိုင်တွယ်တာ အရေးကြီးပါတယ်။

**ဘယ်လို အလုပ်လုပ်လဲ** — `.lower()`, `.strip()`, `.replace()` တို့လို method တွေသုံးပြီး text ကို ပြင်ဆင်ပါတယ်။ `+` နဲ့ f-string သုံးပြီး ပေါင်းစပ်ပါတယ်။

**ဥပမာ**

```python
# String manipulation
raw_input = " Hello AI World  "
clean = raw_input.strip().lower()
print(clean)            # Output: hello ai world

name = "Aung"
message = f"Hi {name}, welcome!"
print(message)           # Output: Hi Aung, welcome!
```

**လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ** — User input တွေမှာ ပိုမိုနေတဲ့ space တွေ၊ အရွယ်အစားမတူတဲ့ အက္ခရာတွေ ပါလေ့ရှိပါတယ်။ ဒီတွေကို သန့်စင်ပြီးမှ ဆက်လက်သုံးရပါတယ်။

## ၈။ Loops

**ဘာကို ဆိုလိုတာလဲ** — Loop ဆိုတာ အလုပ်တစ်ခုကို အကြိမ်ကြိမ် ထပ်လုပ်ပေးတဲ့ နည်းဖြစ်ပါတယ်။

**ဘာကြောင့် လဲ** — တစ်ခါထက် တစ်ခါ ကုဒ်ကို ကူးရေးနေရင် ပင်ပန်းပါတယ်။ Loop သုံးရင် ကုဒ်တိုပြီး ပြင်ရလည်း လွယ်ပါတယ်။

**ဘယ်လို အလုပ်လုပ်လဲ** — `for` loop က list ထဲက item တွေကို တစ်ခုချင်း ယူပြီး အလုပ်လုပ်ပေးပါတယ်။

**ဥပမာ**

```python
# Loop through a list of data
scores = [88, 92, 75, 60]
for score in scores:
    if score >= 80:
        print(f"Score {score}: good")
    else:
        print(f"Score {score}: needs improvement")
# Output:
# Score 88: good
# Score 92: good
# Score 75: needs improvement
# Score 60: needs improvement
```

**လက်တွေ့မှာ ဘာကြောင့် အရေးကြီးလဲ** — Data အများကြီးကို တစ်ခုချင်း စစ်ဆေးတာ၊ model ကို အကြိမ်ကြိမ် သင်ခန်းစာတာ စတဲ့ အလုပ်တွေမှာ loop က မရှိမဖြစ် လိုအပ်ပါတယ်။

## သင်ခန်းစာ အနှစ်ချုပ်

ဒီ module က AI ခရီးလမ်းရဲ့ ပထမအဆင့်ဖြစ်ပါတယ်။ Variable တွေက စကားလုံးတွေ၊ operator တွေက ဝါကျတွေ၊ syntax စည်းမျဉ်းတွေက သဒ္ဒါသဖွယ် ဖြစ်ပါတယ်။ ဒီအခြေခံတွေ ခိုင်မြစေဖို့ အောက်က လက်တွေ့ စာမေးပွဲတွေကို လေ့ကျင့်ပါ။
