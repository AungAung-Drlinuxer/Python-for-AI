# Data Types — Numbers, Strings, Booleans

ဒီ module မှာ Python ရဲ့ အခြေခံ data type သုံးမျိုးဖြစ်တဲ့ Numbers, Strings, Booleans တွေကို လေ့လာမှာ ဖြစ်ပါတယ်။

## ဒီ module မှာ ဘာသင်မလဲ

- Numbers (int နှင့် float) ကို သင်ခဏ်းနားသဘောပေါက်မယ်
- Strings နှင့် စာသားတွေကို ကိုင်တွယ်တတ်မယ်
- Booleans (True/False) ရဲ့ အဓိပ္ပာယ်ကို နားလည်မယ်
- `type()` function နှင့် data type စစ်နည်း သင်မယ်
- Type တွေကို ရောစပ်ဖို့ conversion လုပ်နည်း လေ့လာမယ်

## သင်ခန်းစာစာရင်း

### ၁။ Numbers (int / float)
- ကိန်းပြည့် (int) နှင့် ဒသမ (float) ကိန်းများ
- အခြေခံ သင်္ချာ တွက်ချက်မှုများ

### ၂။ Strings
- စာသားရေးသားခြင်း၊ quote သုံးနည်း
- စာသားများကို ပေါင်းခြင်း (concatenation)

### ၃။ Booleans
- True နှင့် False တန်ဖိုးများ
- Decision လုပ်ဖို့ Boolean အသုံးဝင်ပုံ

### ၄။ Type Conversion
- Type မတူလျှင် ရောစပ်လို့ မရပုံ
- `int()`, `float()`, `str()` တို့နှင့် ပြောင်းနည်း

### ၅။ type() Function
- Data type စစ်ရန် `type()` သုံးနည်း

## မလိုအပ်တဲ့ ရှေ့ပြုအသိပညာ (Prerequisites)

- Python installation ပြီးသားဖြစ်ရမယ်
- Variable နှင့် `print()` function အခြေခံ သိထားရမယ်

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

- AI model တွေရဲ့ score တွေကို ကိန်း (float) အနေနဲ့ သိမ်းချင်တဲ့အခါ
- User ရဲ့ input စာသား (string) ကို ကိုင်တွယ်တဲ့အခါ
- Condition တစ်ခုမှန်/မမှန် (True/False) စစ်ချင်တဲ့အခါ
- String ထဲက ကိန်းကို ကိန်းအဖြစ် ပြောင်းပြီး တွက်ချင်တဲ့အခါ
