# Control Flow — If Statements

Python ရဲ့ **if statement** တွေနဲ့ ပရိုဂရမ်က  ဆုံးဖြတ်ချက် ချမှတ်နိုင်စွမ်းအား အသုံးပြုနည်းကို ဒီ module မှာ လေ့လာပါမယ်။

## ဒီ module မှာ ဘာသင်မလဲ

- `if` statement ဆိုတာ ဘာလဲ၊ ဘာကြောင့် လိုအပ်တာလဲ
- Boolean value တွေနဲ့ comparison operator တွေက `if` ထဲမှာ ဘယ်လို အလုပ်လုပ်လဲ
- Indentation (space ခြားခြင်း) ရဲ့ အရေးကြီးမှု
- `else` နဲ့ `elif` ကိုသုံးပြီး ရွေးချယ်မှု အမျိုးမျိုး လုပ်နိုင်စွမ်း

## Lesson များ

### Topic 1 — if Statement အခြေခံ
- `if` keyword နဲ့ စတင်ပုံ
- Condition (ဦးခံ ပမ်း) တစ်ခုက ဘယ်လို `True` / `False` ဖြစ်သွားလဲ
- Colon (`:`) နဲ့ indentation ခံပွဲ

### Topic 2 — else Statement
- Condition မှားရင် ဘာဖြစ်မလဲ
- `else` block တစ်ခုက ဘယ်လို အလုပ်လုပ်လဲ

### Topic 3 — elif Statement
- Condition အများအတွက် အဆင့်ဆင့် စစ်ဆေးပုံ
- ပထမဆုံး `True` ဖြစ်တဲ့ branch တစ်ခုပဲ အလုပ်လုပ်ပုံ

## Prerequisites

ဒီ module ကို မစခင် ဒီအချက်တွေကို နားလည်ထားဖို့ လိုအပ်ပါတယ်—

- **Variables** — တန်ဖိုးတွေ သိမ်းဆည်းထားနိုင်ခြင်း
- **Comparison operators** — `==`, `!=`, `<`, `>`, `<=`, `>=`
- **Booleans** — `True` နဲ့ `False` value တွေ

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

if statement တွေက ပရိုဂရမ်တိုင်းလိုလိုမှာ ပါဝင်ပါတယ်—

- **ATM စက်** — IF password မှန်ရင် THEN ဝင်ခွင့်ပေးတယ်
- **Weather app** — IF အပူချိန် < 0 ဖြစ်ရင် THEN နှင်း icon ပြတယ်
- **Games** — IF health = 0 ဖြစ်ရင် THEN game over ပြတယ်
- **AI apps** — data တစ်ခုက သတ်မှတ်ထားတဲ့ စည်းမျဉ်းနဲ့ ကိုက်ညီမူ ကွဲပြားတဲ့ လုပ်ဆောင်ချက် လုပ်တယ်
