# Practical Python — Real Project Structure

ဒီ module မှာ Python script တစ်ခုကနေ real program တစ်ခုအဖြစ် တဖြည်းဖြည်း တည်ဆောက်တတ်အောင် သင်ကြားပါမယ်။ နမူနာအနေနဲ့ sales analysis project တစ်ခုကို အဆင့်ဆင့် တည်ဆောက်သွားပါမယ်။

## ဒီ module မှာ ဘာသင်မလဲ

- Organized folder structure တစ်ခုကို ဘယ်လို တည်ဆောက်မလဲ
- Python က file တွေကို path သုံးပြီး ဘယ်လို ရှာတွေ့လဲ
- CSV data ကိုဖတ်ပြီး JSON အနေနဲ့ ဘယ်လို save လုပ်မလဲ
- Code တွေကို reusable functions အဖြစ် ဘယ်လို စုစည်းမလဲ
- အကုန်ပေါင်းပြီး complete data analysis program တစ်ခု ရမယ်

## သင်ခန်းစာ စာရင်း

1. **Project Structure** — ဖိုင်တွေ၊ folder တွေကို စနစ်တကျ စုစည်းနည်း။ data, code, output တွေကို ခွဲခြားထားနည်း။
2. **Python Paths** — Python က file တွေကို ဘယ်နေရာက ရှာလဲ။ Relative path နဲ့ absolute path ကွာခြားချက်။
3. **Working with Files** — CSV file ဖတ်နည်း၊ JSON file save လုပ်နည်း။
4. **Organizing Code** — Code တွေကို function တွေအဖြစ် ခွဲပြီး ပြန်သုံးလို့ရအောင် ရေးနည်း။

## လိုအပ်ချက်များ (Prerequisites)

- Python basics — variable, list, dictionary, function တွေကို နားလည်ထားရပါမယ်
- Python ကို computer မှာ install ထားရပါမယ်
- Terminal/command line အခြေခံကို အနည်းငယ် သိထားရပါမယ်

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

- Script တစ်ခုထဲမှာ code အားလုံး ရေုံကြခဲ့ရတာ ပြဿနာဖြစ်လာလျှင်
- Data file တွေ စတင် များလာလျှင်
- ကိုယ့် project ကို တခြားသူတွေနဲ့ မျှဝေဖို့ လိုလာလျှင်
- AI/data project တစ်ခုကို စတင် တည်ဆောက်ချင်လျှင်
