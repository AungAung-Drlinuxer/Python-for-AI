# Module: Git & GitHub — Version Control

ဒီ module မှာ code တွေကို ဘယ်လို စနစ်တကျ သိမ်းဆည်းမလဲ၊ ဘယ်လို ပြန်ပြင်မလဲ ဆိုတာကို သင်မယ်။

## ဒီ module မှာ ဘာသင်မလဲ

- Git ဆိုတာ ဘာလဲ၊ ဘာကြောင့် လိုအပ်လဲ
- GitHub account ဘယ်လို ဖန်တီးမလဲ
- Repository ကို clone လုပ်ခြင်းနဲ့ အသစ်ဖန်တီးခြင်း
- VS Code ထဲမှာ Git ကို ဘယ်လို သုံးမလဲ
- AI engineer တစ်ယောက်အတွက် version control ရဲ့ အရေးကြီးမှု

## Lesson များ

1. **Version Control ဆိုတာ** — Git က code အတွက် save system ဖြစ်တဲ့အကြောင်း၊ ပြောင်းလဲမှုတွေကို track လုပ်ပုံ၊ ရက်ရောထက် ပြန်သွားနိုင်ပုံ
2. **GitHub Setup** — GitHub account ဖန်တီးခြင်း၊ GitHub က code အတွက် Google Drive လို အလုပ်လုပ်ပုံ
3. **Clone & Create Repos** — ရှိပြီးသား project ကို download လုပ်ခြင်း (clone)၊ project အသစ် စတင်ခြင်း (create)
4. **Git in VS Code** — VS Code editor ထဲကနေပဲ Git commands သုံးပုံ၊ terminal နဲ့ Source Control panel

## မသင်ခင် လိုအပ်ချက်များ (Prerequisites)

- Python အခြေခံ ရေးတတ်ရမယ်
- VS Code install လုပ်ပြီးသား ဖြစ်ရမယ်
- Git ကို ကွန်ပျူတာမှာ install လုပ်ပြီးရမယ်

## ဘယ်အချိန်မှာ အသုံးဝင်လဲ

- Project တစ်ခုရဲ့ progress ကို စနစ်တကျ သိမ်းချင်တဲ့အခါ
- AI project မှာ experiment တွေ လုံခြုံစွာ စမ်းချင်တဲ့အခါ
- အခြားသူတွေနဲ့ code မျှဝေပြီး တစ်နဲ့တစ် လုပ်ဆောင်ချင်တဲ့အခါ
- GitHub ပေါ်မှာရှိတဲ့ AI tools တွေကို ယူသုံးချင်တဲ့အခါ

## မှတ်ချက်

Git မှာ command အများကြီး ရှိပေမယ့် တကယ်လိုအပ်တာက command ၅-၆ ခုပဲ ဖြစ်တယ်။ ဒီ module က အဲဒီ အခြေခံတွေကိုပဲ အာရုံစိုက်ထားတယ်။
